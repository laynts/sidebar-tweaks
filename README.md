# Sidebar Tweaks

サイドバー(Nパネル)のタブの並び順を入れ替える Blender アドオンです。

A Blender add-on that reorders the sidebar (N-panel) category tabs.
Requires Blender 4.2 or later. Licensed under GPL-3.0-or-later.

## 何をするものか

アドオンをいくつも入れていると、サイドバーのタブが増えて、よく使うタブが下のほうになってしまうことがあります。
タブはアドオンが読み込まれた順に並ぶためです。

Sidebar Tweaks を入れると、タブを一覧で好きな順に並べ替えられます。
よく使うタブを上に持ってくれば、タブの間を行ったり来たりせずに済みます。
タブ内のパネルの上下順と開閉状態は変わりません。

## 動作環境

Blender 4.2 以降が必要です。
Blender 5.2.1 (Windows) で動作を確認しています。

## インストール

### リポジトリを登録する（おすすめ）

更新が出たときに、Blender の中から入れ替えられます。

編集 > プリファレンス > エクステンションを入手 を開き、
右上の「リポジトリ」から「リモートリポジトリを追加」を選びます。
URL に次を入れて追加してください。

```
https://laynts.github.io/sidebar-tweaks/index.json
```

一覧に「Sidebar Tweaks」が出るので、インストールを押します。
以降、新しいバージョンを出すとこの画面に更新ボタンが現れます。

「オンラインアクセスを許可」が有効になっている必要があります。

### zip から入れる

[Releases](https://github.com/laynts/sidebar-tweaks/releases) から zip をダウンロードし、
Blender のウィンドウへドラッグ＆ドロップしてください。
展開は不要です。

この方法では、更新のたびに同じ手順で入れ直すことになります。

## 使い方

3D ビューポートのサイドバー(N キー)を開き、「ビュー（View）」タブの「サイドバーのタブ順」パネルを開きます。

一覧の右側の上下ボタンで動かすか、行頭のつまみをクリックしてつまみます。
つまんだ後は押しっぱなしにせず、そのままマウスを上下に動かします。
ホイールや ↑↓ キーでも 1 つずつ動かせます。
左クリックまたは Enter で確定、右クリックまたは Esc で取り消しです。

動かすとその場でサイドバーへ反映されます。
並び順は自動で保存され、次回の起動時にも適用されます。
この自動適用はパネルの「オプション」から切ることもできます。

アドオンを新しく有効にしたときは「一覧を更新」を押してください。
そのタブが一覧の末尾に加わります。

**このパネルは 3D ビューポートにだけ表示されます**。
ほかのエディタのタブ順も、ここから「並び替えるエディタ」を切り替えて設定します。
3D ビューポートのほか、画像 / UV エディター、ノードエディター、動画クリップエディター、
ビデオシーケンサー、ドープシート、グラフエディター、ノンリニアアニメーションに対応しています。

## 制限事項

Blender 標準のタブ（アイテム、ツール、ビューなど）は並び替えられません。
常にサイドバーの先頭に置かれます。

一覧にあるのに、サイドバーに出ていないタブがあります。
Blender は、そのタブの中身が今のモードや選択状態で使えるときだけタブを表示するためです。
並び順そのものは指定したとおりに保たれます。
